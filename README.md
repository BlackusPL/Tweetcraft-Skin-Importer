# How to use?

In Main Menu on the bottom left corner you should see 🎨 button. There you can import your minecraft skin, it could be 64x64, 64x32 and 128x128 (it will be converted to 64x64)

After importing, save your skin and you good to go.

# How to Install?

Install Tampermonkey or Violentmonkey extension then click [install](https://github.com/BlackusPL/Tweetcraft-Skin-Importer/raw/main/Tweetcraft-Skin-Painter.user.js)
